# 超能 NONO · 形态 2 · 表情动画（Lottie 资产）

从原资源 `NONO形态与动作_20261021/资源/nono/super/exp/{1..4}_2.swf` 直接转换而来的
**形态 2（超能 NONO 第二个形态）4 个表情动画**，矢量 Lottie 格式。

> 文件名里的 `_2` 是**形态编号**。客户端按 `exp/<表情ID>_<superStage>` 取资源，
> 所以 `1_2` ~ `4_2` 就是形态 2 玩家能触发的全部 4 个表情。
>
> ⚠️ **原资源把 1 / 2 号表情画反了**：形态 2 的 `exp/1_2.swf` 画的是眯眼吐舌（生气），
> `exp/2_2.swf` 画的是炸毛欢呼（开心），与配置表 `<superExp>` 段
> （id=1 开心、id=2 生气）对不上 —— 是**原始美术资源的编号错误**，不是转换 bug
> （形态 1 的 `1_1` / `2_1` 编号是对的）。
> 本目录按「**名字以配置表为准**」重新配对：表情 id=1（开心）用 `2_2.swf` 的画面，
> id=2（生气）用 `1_2.swf` 的画面。所以**帧数也跟着换了**
> （开心 60 帧、生气 113 帧），`manifest.json` 的 `sourceFile` 字段记录了实际来源。

配套资产：八方向循环走路在 [`../nono-form2-walk/`](../nono-form2-walk/)，
7 个动作在 [`../nono-form2-actions/`](../nono-form2-actions/)，三者取景与宠物锚点一致。

## 接入

```js
const anim = lottie.loadAnimation({
  container: el,
  renderer: 'svg',          // 或 'canvas'
  loop: false,              // 表情播一遍即结束
  autoplay: true,
  path: 'assets/nono-form2-expressions/nono2_exp_happy.json',
});
```

- **4 个表情一律 `loop: false`**（原资源是 `gotoAndPlay(1)`，播一遍就结束；
  配置表 `<exp>` 段没有 `autoEnd` 字段）。
- **摆放按 `petAnchor` 对齐**（见 `meta.json`），不要按画布居中。

## 语义标签（`nono` 字段）· 染色用

4 个表情资产**已打标**（染色/扩展用）。标签是 Lottie 的自定义字段，
lottie-web 忽略它 ⇒ **渲染逐像素不受影响**（本 README 的逐像素基线仍成立）。

染色规则：`dye="solid"` 的填充换成目标色，`dye="shade"` 的换成目标色的深暗版，
**没有 `dye` 字段的一律不染**。本形态的表情里被排除的是：

| 排除对象 | shape | 原因 |
|---|---|---|
| 白色特效（表情周围的小亮点） | 开心 / 悲哀各 shape3、惊讶 shape35、生气 shape27 | 特效，不是本体 |
| **白色的「^ ^」笑眼** | 开心 shape42 | 眼睛 —— 染了会变成目标的深色，表情就废了 |

> **为什么眼睛单列一个角色**：走路的眼睛是浅青 `#ccffff`（本来就不在染色范围里），
> 而**开心**表情的弯弯笑眼是**纯白**的。若按「白色即染」一刀切，
> 同一个角色在不同动画里眼睛颜色会不一致 ⇒ 给它单独一个 `eye` 角色（不染色）。
> 其它三个表情的眼睛本来就是浅青，不受影响。

> ⚠️ **惊讶 / 生气两个表情的耳朵整体是白色的**，标签只把**耳根那一小段**
> 标成 `ear_root`（要染），耳朵其余部分不在染色范围里。

**辉光（glow）标签**：生气 / 悲哀 / 惊讶三个表情的图层带 `glow` 标签
（源 SWF 的 `GLOWFILTER` 峰值参数），开心没有。这批资产的辉光
**没有烘焙进 Lottie** ⇒ `baked: false`，运行时可按标签自己渲染。

完整标签规范见 [`../README.md`](../README.md#️-语义标签nono-字段染色--以后扩展用)。
预览：`http://127.0.0.1:8903/preview/dye.html?form=2`（切「表情」页）

## 音效：无

4 个表情在**原资源里就没有声音**（SWF 里没有内嵌 `sou` 类），客户端的表情分支
（`NonoModel.as` 的 `_expMC.gotoAndPlay(1)`）也不碰 `Sound`。
`manifest.json` 里每个表情的 `audio.status` 为 `missing-from-source`，
**没有编造占位音频**。音效资产在 [`../nono-sounds/`](../nono-sounds/)。

参考帧由 **FFDec 渲染原 SWF** 得到，Lottie 帧由 **lottie-web 在浏览器里渲染**，

|---|---|---|

| 生气 | 1.03% | 139 px |
| 惊讶 | 1.13% | 166 px |
| 悲哀 | 4.34% | 664 px |
| **总体** | **1.82%**（60673 / 2951579 px，2.06%） | |

> 上表是按**画面内容**标注的。开心/生气两个表情的源文件编号对调后（见文首说明），
> 画面本身没变，所以差异率随画面一起互换；整体总量不变，未重跑比对。

## 已知偏差：BLUR / GLOW 滤镜未还原

形态 1 的表情资源**完全没有滤镜**；形态 2 的表情带了不少：

| 资源 | GLOWFILTER | BLURFILTER |
|---|---|---|
| `exp_1_2.swf`（生气） | 247 | — |
| `exp_2_2.swf`（开心） | 112 | — |
| `exp_3_2.swf`（惊讶） | 78 | — |
| `exp_4_2.swf`（悲哀） | 78 | **37** |

Lottie（bodymovin 规范）**没有 glow 滤镜**，只有 Drop Shadow 和 Gaussian Blur
两种滤镜效果；GLU 的 glow 无法直接表达。

- **GLOW** 未还原。好在实测它对像素的影响很小（开心/生气/惊讶三个表情的
  平均差异仍在 0.76%~1.13%，与形态 1 的表情基线同量级）。
  ⇒ 但**参数已经解析出来写进图层的 `nono.glow` 标签**了（峰值 color/blur/strength），
  运行时可以自己补上这圈辉光，不必回头解析 SWF。
- **BLUR** 未还原，这是「悲哀」表情 4.34% 差异的**唯一来源**：
  原资源给 8 个「泪滴」图形加了 `blurX=blurY=15` 的大半径模糊，
  参考帧里泪滴是一团柔和的竖向虚影，Lottie 里是清晰的尖角形状。
  118 帧里有 90 帧受影响。

> 形态 1 的动作脚本曾用「同心描边」近似 glow，实测在吃电池 / 玩魔方 / 玩召唤上
> **加了反而差异更大、体积翻倍**，因此本批资产一律不做滤镜近似，
> 宁可保持矢量干净，也不引入更差的近似。
