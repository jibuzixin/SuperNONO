超能 NONO 桌宠 · macOS 安装说明
================================

版本：__VERSION__（Apple Silicon / M1·M2·M3·M4）
系统要求：macOS 11 Big Sur 或更高版本

一、安装
--------
1. 双击打开 DMG。
2. 把「超能NONO」拖进左边的「Applications（应用程序）」文件夹。
3. 打开「启动台」或「应用程序」文件夹，双击「超能NONO」。
4. 启动后桌面上会出现 NONO，菜单栏右侧会出现 NONO 图标；程序没有 Dock 图标。

二、第一次打开的提示
--------------------
本程序是免费开源软件，没有购买 Apple 开发者证书做公证（Notarization），
所以第一次打开时 macOS 可能提示「无法打开，因为无法验证开发者」或
「已损坏，无法打开」。这不是程序坏了，按下面任一方法放行即可：

方法 A（推荐）
  1. 在「应用程序」里按住 Control 点按「超能NONO」→ 选「打开」。
  2. 弹窗里再点一次「打开」。
  之后就可以正常双击启动。

方法 B（系统设置）
  打开「系统设置」→「隐私与安全性」，在页面下方找到
  「已阻止使用 超能NONO」，点「仍要打开」。

方法 C（提示“已损坏”时）
  打开「终端」，执行：
    xattr -dr com.apple.quarantine /Applications/超能NONO.app
  然后再双击启动。

三、使用
--------
· 左键单击：随机表情
· 左键拖拽：移动 NONO，松手后记住位置
· 右键单击：随机动作
· 菜单栏 NONO 图标：动作 / 表情 / 形态 / 颜色 / 大小 / 速度 / 残影 /
  音效 / 自由走动 / 跟随鼠标 / 隐藏 / 退出
· 退出：点菜单栏 NONO 图标 →「退出」

四、配置与卸载
--------------
配置与窗口位置：
  ~/Library/Application Support/NonoPet/config.toml
渲染缓存（可随时删除，会自动重建）：
  ~/Library/Caches/NonoPet

卸载：先退出程序，然后把「应用程序」里的「超能NONO」删掉；
如需彻底清理，再删除上面两个文件夹。

五、其他
--------
· 本安装包只支持 Apple Silicon（arm64）芯片的 Mac。
· 程序完全离线运行，不联网、不上传任何数据。
· 源码与许可证（MIT）见项目仓库。
